# Upgrade from Milestone 3B to 3C

This is a drop-in code/config upgrade. Preserve your existing `.venv/`, `data/`,
and `artifacts/` directories.

Milestone 3C also includes a small robustness correction to the 3B historical
quantile classifier: if rolling lower/upper quantile thresholds are exactly tied,
equality is classified as the neutral `medium` state rather than being overwritten
into `high`. Your uploaded 3B signal dates did not actually contain tied Fed-funds
thresholds, so this is a latent edge-case correction rather than a material rewrite
of the 3B conclusions.

After copying the upgrade files:

```powershell
python -m pip install -e ".[dev,ml]"
pytest
quant-research run-milestone3b
quant-research run-milestone3c
```

Rerunning 3B is recommended once so the artifacts are generated by the corrected
classifier. 3C itself does not depend on regime labels and does not retrain the
alpha models.
