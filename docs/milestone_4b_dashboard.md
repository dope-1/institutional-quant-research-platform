# Milestone 4B — Institutional Dashboard

Milestone 4B adds a read-only Next.js presentation layer to the frozen research
platform. It does not alter features, labels, model specifications, portfolio
rules, optimizer settings, regime definitions, or the 2026 prospective record.

## Architecture

- Next.js 16 and TypeScript
- Tailwind CSS and shadcn/ui primitives
- Recharts for accessible, responsive research charts
- `web/public/data/*.json` as the primary data source
- FastAPI as a supplemental research interface, not a page-load dependency

The ten JSON files are generated by `quant-research export-web`. The dashboard
imports the resulting static snapshot at build time, allowing every route to be
prerendered.

## Evidence policy

The overview and holdout routes visibly retain all four negative 2026 mean Rank
IC values. Positive partial-year portfolio results are shown as separate
portfolio evidence and do not replace or obscure the cross-sectional ranking
record. Historical and prospective periods remain explicitly labeled.

## Routes

| Route | Purpose |
| --- | --- |
| `/` | Research status, audit summary, and prospective evidence |
| `/models` | Frozen model registry and validation-only selection policy |
| `/performance` | Historical, optimized, and holdout portfolio metrics |
| `/risk` | Partial-year realized risk and return surface |
| `/explainability` | Post-hoc SHAP features and interactions |
| `/regimes` | Conditional historical Rank IC diagnostics |
| `/optimization` | Frozen optimizer settings and concentration |
| `/holdout` | Complete matured 2026 Rank IC and portfolio record |
| `/data-quality` | Coverage checks and review flags |
| `/methodology` | Target, features, splits, and chronology safeguards |

```text
eslint . --ignore-pattern dist --ignore-pattern .next

```

The production build compiled successfully, passed TypeScript checking, and
